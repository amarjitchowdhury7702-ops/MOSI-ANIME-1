How do I get a free YouTube API key? (5 minutes)
  1. Open console.cloud.google.com and sign in with Google.
  2. Create a project (top bar → New Project → name it "MOSI ANIME").
  3. Go to APIs & Services → Library, search for YouTube Data API v3 and click Enable.
  4. Go to APIs & Services → Credentials → Create credentials → API key.
  5. Click the key → API restrictions → restrict it to YouTube Data API v3 → Save.
  6. Copy the key, paste it above and click Save key. It's free (10,000 units a day), and MOSI caches results so that's plenty.
